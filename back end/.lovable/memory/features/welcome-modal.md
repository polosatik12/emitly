Полноэкранная модалка `WelcomeModal` (src/components/WelcomeModal.tsx), смонтированная в `AppLayout` поверх мобильной и десктопной разметки.

Логика показа:
- Условие видимости: `isAuthReady && user && !loading && trial_started_at === NULL`.
- Показывается на каждом маршруте приложения и при каждом входе, пока триал не активирован.
- Скрыта только на `/service-catalog` (чтобы пользователь мог оформить тариф) и на `/auth`/лендинге.
- Шаг (0 → 1) сбрасывается при смене маршрута, чтобы окно начиналось заново.

Структура (2 шага):
1. Знакомство с возможностями Emitly + кнопка «Далее».
2. Подарок «7 дней Pro бесплатно» + основная CTA «Начать 7 дней бесплатно» (вызывает `start_trial_if_needed` RPC и обновляет `usePlan`) + вторичная ссылка «Сразу выбрать тариф →» (только переход на `/service-catalog`, триал НЕ стартует).

Закрыть окно никаким другим способом нельзя (нет крестика, нет клика по фону). `usePlan` НЕ запускает триал автоматически — только пользовательский клик по «Начать 7 дней бесплатно».
