
Проблема: TradingView symbol-overview виджет показывает "Инструмент доступен только на TradingView" для RNFT (РуссНефть) и других малоликвидных эмитентов MOEX. Это НЕ проблема авторизации — TradingView просто не отдаёт данные по этим тикерам в бесплатных embed-виджетах независимо от префикса (`MOEX:`, `RUS:`).

Малоликвидные российские бумаги (RNFT, многие 2-3 эшелон) физически отсутствуют в free-фиде TradingView. Никакая авторизация это не починит — это ограничение их бесплатных виджетов.

## Решение: гибридный подход

Используем **MOEX ISS API** (бесплатный, официальный, покрывает ВСЕ российские акции) как основной источник, но стилизуем график максимально близко к TradingView — area chart с градиентом, переключатель периодов в виде пилюль, тултип, светлая тема.

У нас уже есть `MoexChart.tsx` на recharts. Доработаем его, чтобы визуально был **неотличим от TradingView**:

### Что меняем

1. **`src/components/MoexChart.tsx`** — рефакторинг под TradingView-look:
   - Периоды как у TradingView: `1Д / 5Д / 1М / 3М / 6М / 1Г / 5Л / Все` (пилюли сверху, серый текст, активная — чёрная подчёркнутая, как у TV).
   - Для `1Д` и `5Д` использовать интервал MOEX `interval=10` (10-минутные свечи).
   - Отображение текущей цены и изменения над графиком (крупно, как у TV): `1 234,56 ₽ +12,34 (+1,23%)` зелёным/красным.
   - Зелёная/красная заливка с градиентом до прозрачного (точно как TV).
   - Тонкая ось Y справа, без рамок и сетки — только горизонтальная пунктирная линия от последнего значения (как у TV).
   - Тултип: вертикальная линия + плашка с датой/ценой в стиле TradingView.
   - Шрифт Inter, размеры подогнаны под TV (10–11px для осей, 22px для цены).

2. **`src/pages/EmitterProfilePage.tsx`**:
   - Заменить `TradingViewMiniChart` на доработанный `MoexChart`.
   - Высота: 280 desktop / 220 mobile.
   - Убрать «Полный график в TradingView» (необязательно, можно оставить ссылкой мелким текстом).

3. **Удалить** `src/components/TradingViewMiniChart.tsx` (больше не используется).

### Почему это правильно

- MOEX ISS — официальный публичный API без ключей, работает для **всех** 55 эмитентов из `src/data/emitters.ts`.
- Визуально пользователь не отличит от TradingView — те же цвета, те же переключатели, тот же area-chart с градиентом.
- Никаких "Инструмент доступен только на TradingView" — данные реальные и полные.
- Уже подтверждённо работало в предыдущей итерации — нужно только довести дизайн.

### Альтернатива (если пользователь настаивает на именно TV)

Единственный способ заставить TradingView отдавать RNFT — это платная подписка TradingView + использование их Charting Library (≈$500/мес лицензия + хостинг библиотеки). Это **не вариант** для текущего проекта.
